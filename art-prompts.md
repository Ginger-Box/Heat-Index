# Prompts for card art (Nano Banana)

How to use:
1. First generate **one** robot with the full prompt (style + description).
2. For the rest, attach the first image and write: «Same style, palette and framing as the attached image:» + the robot's description. Then the set will look like one series.
3. Format 1:1, 1024×1024. I'll bring the result down to card size and to the game's pixel grid myself.

## Common style (paste at the start of every prompt)

```
16-bit pixel art sprite of a combat robot for a cyberpunk card game. Underground robot arena in a neon-lit junkyard.
Chunky readable silhouette, 3/4 front view, full body, centered, robot fills ~70% of the frame.
Strict limited palette: deep purple-black background (#07060c) with subtle Bayer dithering, neon magenta (#ff2a8a)
and cyan (#00f0ff) rim light, hazard yellow (#ffe600) accents, rusty orange metal. Crisp hard pixels, no anti-aliasing,
no gradients except dithering, dark 1-pixel outline around the robot. Worn, scrap-built, mismatched parts, rust and decals.
No text, no letters, no numbers, no UI, no card frame, no watermark. Square 1:1.
```

## Robots — one per class

**Spark (Basic class — a cheap reliable bot)**
```
Robot: "Spark" — a small scrappy maintenance bot the size of a trash can, one big round cyan eye lens, stubby arms with
pliers, exposed wires, a tiny antenna with a crackling spark on top. Humble, cheap, reliable.
```

**Titan (Armor class — the guard)**
```
Robot: "Titan" — a massive bipedal riot tank built from layered scrap armor plates with yellow-black hazard stripes,
a huge tower shield bolted to its left arm, tiny glowing visor slit, heavy stance. Looks unmovable, a wall of steel.
```

**Raptor (Maneuver class — bypasses guards)**
```
Robot: "Raptor" — a sleek predator robot with digitigrade raptor legs, low forward-leaning pose, blade claws,
small back thrusters firing cyan jets, pixel speed lines behind it. Fast, agile, dangerous.
```

**Fixdrone (Repair class — heals and cools)**
```
Robot: "Fixdrone" — a small hovering repair drone with four little rotors, a welding arm and a nozzle spraying
a glowing green repair beam and cold mist, a white cross decal on its hull. Friendly, busy.
```

**Apocalypse (Blast class — explodes on death)**
```
Robot: "Apocalypse" — a walking bomb robot with a cracked reactor core in its chest glowing hot orange, warning
symbols painted on its plates, smoke leaking from seams, heavy fists. Looks like it could blow at any moment.
```

**Bull (Charge class — strikes immediately)**
```
Robot: "Bull" — a hulking battering-ram robot with two bent steel horns, head lowered mid-charge, steam blasting from
vents on its snout, red heat glow on the horns. Pure momentum.
```

**Stormcaller (Shock class — overheats enemies)**
```
Robot: "Stormcaller" — a tall gaunt robot whose head is a tesla coil, arms ending in copper prongs, crackling
cyan-white electric arcs jumping between its hands and the ground. Menacing, humming with power.
```
